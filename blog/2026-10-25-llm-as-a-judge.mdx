### Self-Preference Bias

Self-preference bias is when the judge scores documents generated by its own model higher than documents generated by other models or written by humans.

This happens because an LLM is a statistical predictor of the next token. It has been trained to produce a particular kind of output, so when it sees output that looks like its own, it treats it as higher quality and more likely to be correct.

To mitigate it:

- **Don't write the judge's prompt with the model that generated the documents.** Write it by hand, or use a different model.
- **Use a different model as the judge** from the one that generated the output being judged.

That's the approach we're taking.
